# Taxonomy

Use these values for `pattern` and `page_type`. If nothing fits, use the closest
term and add a specific word to `tags`. Add a new term here only when three or
more entries would use it.

## Patterns
| Term | Covers |
|---|---|
| hero | Above-the-fold headline, subhead, primary CTA, hero visual |
| navigation | Top nav, sticky headers, mobile menus |
| mega-menu | Large dropdown navigation with grouped links/previews |
| feature-grid | Feature sections, bento grids, alternating feature rows |
| content-grid | Galleries and collections of browsable items: thumbnail grids, card lists, featured item + grid |
| social-proof | Logo clouds, testimonials, stats, case-study strips |
| pricing-table | Plan comparison, billing toggles, feature matrices |
| cta-section | Closing call-to-action blocks, newsletter capture |
| faq | Accordions, Q&A lists |
| footer | Site footers |
| search | Search bars, structured search, results layout |
| command-palette | Cmd+K launchers, quick actions |
| filters | Faceted filters, sort, chips |
| onboarding | First-run flows, checklists, step-by-step setup |
| auth | Sign-up, sign-in, passwordless, SSO |
| form | Multi-field forms, validation, multi-step forms |
| empty-state | Zero-data screens, first-use prompts |
| dashboard | KPI cards, overview screens (the whole screen) |
| chart | Individual data visualisations: chart types, zoom, tooltips, legends, transitions |
| 3d | WebGL/3D: product viewers, configurators, hero scenes, scroll-driven scenes, shader backgrounds |
| data-table | Tables, lists with bulk actions |
| modal | Dialogs, sheets, drawers, popovers |
| feedback | Toasts, inline alerts, loading/skeleton states |
| checkout | Cart, payment, order summary |
| product-detail | Product pages, galleries, variant pickers |
| settings | Preferences, account and billing pages |
| design-tokens | Foundations: colour scales and themes, surfaces, elevation and materials, radii, type scales |
| motion | Transitions, springs, shared-element and scroll-driven motion, micro-interactions |
| accessibility | Focus indicators, keyboard models, error summaries, reduced-motion/contrast handling |
| ui-primitives | (sources only) headless accessible component libraries |
| panels | Split panes, dockable tabs, dashboard tiles: resizable and persisted workspace layouts |
| graph | Node-link diagrams: dependency and architecture graphs, layered/DAG and force layouts, layout engines (sources) |
| map | Interactive maps: basemaps, markers and clusters, live vehicle layers, heatmaps, geofences, fly-to |
| ai-chat | AI conversation UI: threads, streaming answers, composer, stop/retry/edit/branch |
| agent-activity | Agent plans, step and tool-call logs, progress of long or background runs, interrupt/redirect |
| ai-review | Human oversight of AI actions: approval prompts, permission modes, diffs with accept/reject, checkpoints |
| ai-provenance | Citations and sources, AI labelling and disclosure, model/version labels, audit trails |
| ai-assist | Inline AI in ordinary screens: ghost-text autocomplete, rewrite in place with accept/reject, AI form fill, AI command menus, inline summaries |

## Page types
landing · pricing · product · checkout · dashboard · onboarding · auth · settings · docs · search-results · app

## Tags (free-form, but prefer these)
Style: `minimal` `dark` `editorial` `playful` `glass` `gradient` `brutalist` `illustrative`
Audience: `saas` `b2b` `b2c` `ecommerce` `devtools` `consumer-app`
Behaviour: `animated` `sticky` `keyboard` `progressive-disclosure` `responsive` `interactive`
Other: `data-viz` `accessible` `open-source` (code is licensed for reuse)
3D: `webgl` `product-viewer` `configurator` `hero-3d` `scroll-scene` `shaders` `ar`
AI: `streaming` `tool-calls` `human-in-the-loop` `citations` `generative-ui`
