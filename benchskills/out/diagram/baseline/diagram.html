Read it as a list
  1. Add. A person gives ux-add a URL or screenshot. It captures it with capture.mjs, checks catalog.json for duplicates, writes one entry.md per pattern, runs npm run catalog, commits to main and republishes the gallery.
  2. Library. Guides, source profiles, patterns and benchmark evidence (bench*/).
  3. Find. Later, a person asks ux-find for a pattern. It reads guides/README.md, runs find.mjs, reads catalog.json and returns the top three references; it can rebuild one as example.tsx.
