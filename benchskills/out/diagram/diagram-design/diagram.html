How a reference becomes an answer

A person gives ux-add a URL or a screenshot. Later, a person asks ux-find for a pattern. In between, the catalog is what gets rebuilt, and what gets read.

Adding a reference

  1. A person gives ux-add a URL or a screenshot.
  2. It captures it with the Playwright script capture.mjs: desktop and mobile screenshots, and element crops with source.html and styles.json.
  3. It checks catalog.json for duplicates, then writes one entry.md per pattern, rated 3 to 5, with flat frontmatter.
  4. npm run catalog regenerates catalog.json, CATALOG.md, SOURCES.md and gallery/data.js.
  5. The change is committed to main and the published gallery is republished.

Finding a pattern, later

  1. A person asks ux-find for a pattern.
  2. It reads guides/README.md, runs find.mjs (vocabulary in aliases.json) and reads catalog.json.
  3. It returns the top three references with screenshots, techniques and code.
  4. Optionally, it rebuilds one as example.tsx (React + Tailwind).
