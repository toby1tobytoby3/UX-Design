**Pick it for**

- **React Aria Components**: Default for an app UI in our stack, and the only free choice when you need accessible date pickers, data tables, trees or drag and drop.
- **Radix Primitives**: Overlays, menus, tabs, tooltips and toasts where you don't need a combobox, date picker, table or tree, and small bundle matters.
- **Base UI**: A Radix-style API that also needs a combobox, autocomplete or toast, maintained by a funded team (MUI).
- **Ariakit**: Custom composite widgets (command menus, comboboxes with tabs, toolbars) where you need fine control over focus and stores.
- **Headless UI**: Simple Tailwind apps that need a dialog, menu, listbox, combobox or tabs and nothing harder.

**Pick it for**

- **Motion (Motion for React)**: App motion that CSS can't do well, such as interruptible springs, drag and gestures, list reorder and exit animations, `layoutId` tab underlines, or orchestrated sequences.
- **CSS + View Transitions (the platform)**: The default for app motion, such as hover, press, popover and dialog enter/exit, route and shared-element transitions in Next, scroll progress bars and condensing headers.
- **AutoAnimate**: Lists, tables and stacks whose items come and go (notifications, filters, kanban columns) and you want motion with one line of code.
- **GSAP**: Marketing and storytelling pages, where sequenced timelines, pinned scroll scenes and SVG/text effects must behave the same in every browser.
- **React Spring**: Physics-driven values in an existing React Spring codebase, or data visualisations interpolating many values with springs.
- **anime.js**: Framework-agnostic or vanilla pages that want GSAP-style timelines under MIT, or small interactive pieces outside React.

**Pick it for**

- **Apache ECharts**: Data-heavy dashboards that need zoom, drill-down, live updates, large datasets or specialist charts (sankey, heatmap, candlestick, treemap, geo).
- **Recharts**: Everyday product and dashboard charts in our React/Next app (lines, bars, areas, donuts) with up to a few thousand points.
- **visx**: Signature or bespoke charts where design control matters more than speed of build, inside the React app.
- **Observable Plot**: Report, documentation and analysis charts; server-rendered or static charts; quick exploration.
- **AG Charts Community**: Teams already using AG Grid, or business dashboards where built-in keyboard accessibility matters and bundle size does not.
- **D3**: Editorial, one-off or highly custom visualisations; or use its maths modules (scales, shapes, formats) under React rendering.
- **TradingView Lightweight Charts**: Prices, balances, portfolio or any financial time series where pan/zoom feel matters.
- **uPlot**: Monitoring, metrics and real-time or very long time series where speed and size beat everything else.
- **Tremor**: Reference for the Tailwind dashboard look. To build that look, use Recharts with our tokens rather than the npm package.
